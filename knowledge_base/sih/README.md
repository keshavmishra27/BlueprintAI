# SIH Winner Knowledge Base

This directory contains the knowledge-base layer for the BlueprintAI decision-making system. It houses historically verified Smart India Hackathon (SIH) winning projects and the patterns extracted from them.

**Important Concept**: The knowledge base is the **evidence layer**. It provides historical evidence of successful approaches to various problems. It does *not* execute game theory or logic—it simply acts as a queryable foundation for the outer decision engine.

## Directory Structure

- `raw/`: Raw collected evidence files. This is the source of truth for where information came from.
- `normalized/`: Clean, structured project records conforming to the `SIHProject` schema.
- `patterns/`: Evidence-backed semantic patterns discovered from the dataset.
- `schema/`: Pydantic models used to enforce structure and validation.
- `pipeline/`: Python scripts to ingest, normalize, deduplicate, and validate the knowledge base.

## Schemas

- **Source Schema (`source.py`)**: Preserves the exact source (URL, title, extracted text, notes).
- **Project Schema (`project.py`)**: Defines the WHAT, WHY, HOW, technical features, and decision-relevant features.
- **Pattern Schema (`pattern.py`)**: Defines cross-project semantic patterns with explicit linkages to the projects that provide the evidence.

## Data Pipeline

To update the knowledge base with new raw data:

1. Add raw JSON files conforming roughly to the project shape (or just containing raw source evidence) into `raw/`.
2. Run the pipeline from the `sih` directory:
   ```bash
   python pipeline/main.py
   ```
3. The pipeline will normalize, validate against Pydantic models, deduplicate, and output the clean JSON files to `normalized/` along with a `statistics.json` report.

## AI Pattern Extraction

Semantic patterns are currently extracted AI-assisted via inspection of the normalized dataset, not auto-generated by the python pipeline.
